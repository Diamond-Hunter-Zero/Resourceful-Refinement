# Choral Clusters Biome Implementation Plan

## Summary
Implement `resourceful_refinement:choral_clusters` as a custom outer-End biome for Minecraft 1.21.1 NeoForge, using BetterEnd's `CrystalMountainsBiome` as the terrain reference while replacing Fabric/BCLib systems with Resourceful Refinement-native NeoForge, data-pack, and mixin infrastructure.

## BetterEnd Reference Findings
- BetterEnd's Crystal Mountains are generated by a raw-generation structure, `MountainStructure`, which places a large `CrystalMountainPiece`.
- `CrystalMountainPiece` writes terrain mass directly into chunks using radius, height, heightmaps, simplex noise, and biome-edge clamping.
- Aurora crystal pillars are generated inside that structure piece after terrain mass is placed; the crystal columns scale with surface height and are written directly into the chunk.
- `BigAuroraCrystalFeature` is separate and creates freestanding/cave crystals with BCLib SDF hex-prism utilities.
- BetterEnd's biome distribution, surface rules, and End biome injection are handled through BCLib/BetterX, so Resourceful Refinement needs its own NeoForge-compatible layer.

## Key Implementation Changes
- Add worldgen keys and data for `resourceful_refinement:choral_clusters`, `resourceful_refinement:choral_cluster_mountain`, `resourceful_refinement:choral_cluster_mountain_set`, and the biome tags needed for End classification and structure placement.
- Add a `worldgen/choral` Java package containing the custom mountain structure, structure piece, deterministic noise helper, centralized generation settings, crystal pillar generator, and named pillar presets.
- Register the custom structure type and structure piece type through the existing Resourceful Refinement registry setup.
- Add first-pass content blocks for generation: `chorus_crystal` and `choral_end_stone`.
- Add a focused mixin on the vanilla End biome source so Choral Clusters can replace rare outer-End highlands/midlands using distance gates and deterministic noise.
- Keep surface handling explicit inside the structure piece for v1 instead of porting BetterEnd's BCLib surface-rule codecs.
- Generate Chorus Crystal pillars as a mixture of vertical columns, slanted shards, and pointed/tapered formations.

## Tunable Parameters
Generation constants are centralized in `ChoralClusterGenerationSettings` so terrain and crystals can be adjusted without hunting through the algorithms.

| Parameter Area | Examples | Visual Effect |
| --- | --- | --- |
| Biome distribution | outer-End minimum distance, biome noise scale, detail scale, threshold | Controls how far out and how often Choral Clusters appear. |
| Mountain structure | structure spacing, separation, salt | Controls how densely custom mountains attempt to generate inside the biome. |
| Terrain mass | island radius, height multiplier, edge sample radius, terrain noise scales, valley sharpness | Controls asteroid footprint, verticality, peak roughness, and biome-edge blending. |
| Pillar counts | min/max count | Controls crystal density per processed chunk. |
| Pillar size | width/radius range, length range, monumental chance | Controls ordinary and rare oversized crystal formations. |
| Pillar orientation | vertical/slanted/pointed weights, slant angle range | Controls the mix of upright spires, diagonal impalement shards, and tapered spikes. |
| Pillar shape | taper strength, root depth | Controls pointed tips and how deeply pillars embed into terrain. |

Named presets are provided as Java records: `balanced`, `dense_spires`, `wide_asteroids`, and `chaotic_shards`. The active preset is selected through `ACTIVE_PRESET` for fast iteration.

## Test Plan
- Run `.\gradlew.bat compileJava`.
- Run `.\gradlew.bat processResources`.
- Start a dev client/server and create a new End test world.
- Verify `/locate biome resourceful_refinement:choral_clusters` succeeds in the outer End.
- Verify `/locate structure resourceful_refinement:choral_cluster_mountain` succeeds inside or near the biome.
- Verify mountains form tall peaks and valleys without chunk-boundary tearing.
- Verify Chorus Crystal pillars generate vertically, diagonally, and as pointed/tapered formations.
- Verify preset/constant changes visibly alter terrain height, island density, pillar width, length, and slant without code rewrites.
- Verify existing vanilla End biomes and Resourceful Refinement geyser structures still generate.
- Verify save/load preserves custom structure pieces without NBT or codec errors.

## Assumptions
- No new dependency such as BCLib, BetterEnd, or TerraBlender is added.
- BetterEnd code is used as a behavioral reference, not copied wholesale.
- First implementation focuses on terrain, biome placement, Chorus Crystal generation, and extension points for later v0.4 resources.
- Crystal Drills, GLARE networks, transporters, and other later v0.4 systems remain out of scope.
